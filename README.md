# Cyber Bloom — Hand & Smile Tracking

A webcam-driven interactive experience: pinch to bloom flowers from your
fingertips, make a fist to close them, air-tap the top bar to switch flower
types, and smile at the camera for a surprise message.

Built with vanilla JS, Canvas 2D, and MediaPipe Hands / Face Mesh (loaded
from CDN — no build step, no dependencies to install).

## Run locally
Just open `index.html` in a browser, or serve the folder with any static
file server (camera access requires HTTPS or localhost).

## Deploy
This is a static site — deploy the folder as-is to Vercel, Netlify, or
GitHub Pages. No build command or output directory needed.
